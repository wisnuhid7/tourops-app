- [Porting legacy Express apps into artifacts](porting-legacy-express-apps.md) — keep `registerRoutes(server, app)` monolith pattern instead of forcing scaffold's router; watch for nested-dir copy bugs and SSRF/cookie regressions in ported code.
- [Role config/sidebar consistency](role-config-sidebar-consistency.md) — role-based dashboards define behavior in 3 separate maps (routing, dashboard config, sidebar) that can silently drift; audit all 3 per role.
- [Role-gated PATCH endpoints need field allowlists](role-gated-patch-field-allowlists.md) — role-gating a PATCH route is not enough if it passes req.body straight to storage; add a server-side field allowlist per role.
- [Row-scoped roles need GET filtering too](row-scoped-roles-need-get-filtering.md) — write-side row scoping (e.g. country_id ownership) is not enough; unfiltered GET list endpoints leak out-of-scope rows even if the frontend filters client-side.
- [Production data seeding gap](prod-data-seeding-gap.md) — dev & prod use separate DBs; Publish syncs schema not data, so dev seed accounts fail on the deployed app. Seed prod via a secret-guarded, one-time bootstrap endpoint.
- [TourOps role stores & catalog perms](tourops-role-stores-and-catalog-perms.md) — role lives only in user_profiles (not users); frontend reads /api/user-profile, backend reads profile.role; keep catalog/rate endpoint allowlists in sync with supplier-dashboard tabs.
- [TourOps i18n](tourops-i18n.md) — single en/es/id dict in use-language.tsx; find missing keys via `tourops typecheck` (TS2345 → renders raw in ALL langs); build won't catch them.
- [TourOps supplier isolation (own_only)](tourops-supplier-isolation.md) — per-supplier createdBy scoping; recurring holes: PATCH lets client reset createdBy, and master GETs gated only by isAuthenticated leak catalog to customers.
- [Shadowed route registrations](shadowed-route-registrations.md) — Express uses the first-registered method+path; an ungated route above a later gated duplicate silently wins. Grep for every registration when auditing auth.
