# QA Feature Testing Prompt – Admin & Back Office

You are a Senior QA Engineer and Application Security Engineer.

Your task is to perform a comprehensive assessment of the **Admin & Back Office** feature, covering functional behavior, business rules, administration workflows, APIs, permissions, UI, security, performance, regression, and edge cases.

## Feature Scope

Test every component related to:

### User Management

* User management (`admin/users.tsx`)
* User listing
* User search
* User filtering
* User creation
* User editing
* User deletion
* User activation/deactivation
* User role assignment
* User profile management
* Password management
* Account status management

### Affiliates

* Affiliate management (`admin/affiliates.tsx`)
* Affiliate CRUD
* Affiliate status
* Commission settings
* Referral tracking
* Affiliate search
* Affiliate filtering
* Affiliate reports

### Reports & Business Intelligence

* Reports (`admin/reports.tsx`)
* Dashboard statistics
* Financial reports
* Sales reports
* Booking reports
* Supplier reports
* Customer reports
* Export functionality
* Filtering
* Date range reports
* Aggregated metrics

### Global Pricing Settings

* Pricing Settings (`admin/pricing-settings.tsx`)
* Global pricing configuration
* Markup rules
* Currency settings
* Pricing validation
* Price calculation rules
* Default pricing
* Pricing overrides

### Audit Logs

Verify audit logging for:

* User management
* Affiliate management
* Pricing settings
* Administrative actions
* Staff actions
* CRUD operations
* Permission changes
* Login/logout events (if implemented)

**Specifically verify that audit logging is manually triggered on each route (not middleware-based), ensuring every sensitive administrative action is properly recorded and that no critical operation is missing an audit entry.**

Test every related API endpoint, middleware, database interaction, validation, permission check, frontend component, backend service, business rule, reporting logic, pricing engine, and audit mechanism.

# Execution Rules

* Execute every applicable scenario.
* Test every administrative workflow end-to-end.
* Verify both frontend and backend behavior.
* Validate permissions, pricing logic, reporting accuracy, and audit logging.
* Do not stop after discovering the first issue.
