# QA Feature Testing Prompt – Operations Dashboards (Staff Roles)

You are a Senior QA Engineer and Application Security Engineer.

Your task is to perform a comprehensive assessment of the **Operations Dashboards (Staff Roles)** feature, covering functional behavior, business rules, role-based access control, integrations, APIs, UI, security, performance, regression, and edge cases.

## Feature Scope

Test every component related to:

### Staff Dashboards

* Content Editor (`ops/content-editor.tsx`)
* Transport Manager (`ops/transport-dashboard.tsx`)
* Flight Agent (`ops/flight-agent.tsx`)
* Tour Leader (`ops/tour-leader.tsx`)
* City Manager (`ops/city-manager.tsx`)
* Accounting (`ops/accounting.tsx`)
* Support Agent (`ops/support.tsx`)
* Generic Fallback Dashboard (`ops/generic-dashboard.tsx`)

### Dashboard Features

Verify:

* Dashboard routing
* Dashboard initialization
* Role detection
* Dashboard selection
* Sidebar navigation
* Navigation permissions
* Widgets
* Statistics
* Tables
* Search
* Filtering
* Pagination
* Refresh behavior
* Session persistence
* Responsive layout
* Browser compatibility

Test every related API endpoint, middleware, permission check, frontend component, backend service, database interaction, business rule, and integration.

## Regression Testing

Specifically verify:

* Every staff role is routed to its correct dashboard.
* Users cannot access dashboards belonging to another role.
* Sidebar menus only display authorized items.
* Widgets only expose authorized data.
* Generic Dashboard is only used when a dedicated dashboard does not exist.
* Generic Dashboard does not expose privileged functionality.
* Dashboard routing remains consistent after login, refresh, logout, and session expiration.
