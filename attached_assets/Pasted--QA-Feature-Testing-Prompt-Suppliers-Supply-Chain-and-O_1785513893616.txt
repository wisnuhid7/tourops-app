# QA Feature Testing Prompt – Suppliers & Supply Chain and Operations Dashboards

You are a Senior QA Engineer and Application Security Engineer.

Your task is to perform a comprehensive assessment of the **Suppliers & Supply Chain** and **Operations Dashboards** features, covering functional behavior, business rules, integrations, APIs, permissions, UI, security, performance, regression, and edge cases.

## Feature Scope

### Suppliers & Supply Chain

Test every component related to:

* Supplier portals

  * Airline Supplier
  * Hotel Manager
  * Guide Manager
  * Sights Manager
* Supplier authentication
* Supplier authorization
* Supplier dashboards
* Supplier profile management
* Supplier navigation
* Hotel catalog management
* Sight catalog management
* Transport company catalog management
* Airline agency catalog management
* Supplier catalog CRUD
* Supplier ownership validation
* Supplier search, filtering, and pagination
* Rate Cards (`admin/rate-cards.tsx`)
* Numeric price columns stored as strings in the insert schema
* Airline flight search
* Simulated airline pricing
* Distance-based pricing
* Seasonality pricing
* `supplier/airline-search.tsx`
* Redirect into supplier tab
* Partial integration validation
* Transport module
* Bus types
* Transport routes
* `/admin/transport`
* `/ops/transport`
* Duplicate route consistency

### Operations Dashboards

Test every dashboard related to:

* Content Editor (`ops/content-editor.tsx`)
* Transport Manager (`ops/transport-dashboard.tsx`)
* Flight Agent (`ops/flight-agent.tsx`)
* Tour Leader (`ops/tour-leader.tsx`)
* City Manager (`ops/city-manager.tsx`)
* Accounting (`ops/accounting.tsx`)
* Support Agent (`ops/support.tsx`)
* Generic Fallback Dashboard (`ops/generic-dashboard.tsx`)

Test every related API endpoint, middleware, permission check, frontend component, backend service, database interaction, business rule, and navigation flow.
