# Tourop — Full Client Tour Booking Scenario

## Replit Developer Testing Instructions

## Objective

Now that Tourop has been populated with proper data, we need to test a complete real-world booking scenario from start to finish.

This test must prove that Tourop can manage the full tour operation lifecycle:

Client/customer selects a tour → client chooses departure date → client creates booking → passengers are added → passengers log in → passenger information is completed → payment is recorded → operations reviews booking → suppliers are assigned → transport/hotel/guide services are confirmed → tour leader is assigned → documents are generated → messages/notifications are tested → trip is operated → booking is completed.

This must be tested like a real tour company workflow, not just page-by-page testing.
