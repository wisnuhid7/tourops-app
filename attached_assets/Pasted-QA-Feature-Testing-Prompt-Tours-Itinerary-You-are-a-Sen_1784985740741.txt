Regression Testing

Specifically verify:

- GPT-4o fallback generator works when OpenAI is unavailable.
- Draft tours never appear publicly.
- Published tours display correctly.
- Starting From pricing always uses the lowest open departure.
- Base price fallback is used only when no valid departures exist.
- Child pricing never exceeds adult pricing.
- Browse filters work correctly when combined.
- Tour brochure matches published content.
- AI-generated itineraries can be edited without data corruption.
