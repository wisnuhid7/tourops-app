## Private Tour

Customer:

↓

Select private tour

↓

Select date

↓

Select passenger

↓

Select services

↓

Checkout

↓

Payment

↓

Booking created


Verify:

- Correct price
- Correct passenger count
- Correct booking status
- Correct payment status
- Booking visible after completion


Negative:

- Past date
- Invalid passenger count
- Missing required data
- Duplicate submit

## Group Tour

Test:

Create group booking.

Verify:

- Departure price used.
- Group capacity correct.
- Available seats correct.
- Booking status correct.


Negative:

- Join full group.
- Join expired group.
- Join without code.
- Invalid code.
- Reuse code.
