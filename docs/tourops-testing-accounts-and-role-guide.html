Required transaction testing order

Admin setup → Destination data → Supplier catalogs and rates → Tour itinerary → Content and images → Pricing → Departure → Publish tour → Customer booking → Operations assignments → Supplier confirmations → Accounting payment → Tour Leader and Support

1. Administration and master data

  1. Super Admin prepares staff roles and system settings.
  2. Country and City Managers prepare destination data.
  3. Hotel, Guide, Sights, Airline, and Transport Managers prepare catalogs and rates.

2. Tour creation

  1. Tour Builder creates the tour and complete itinerary.
  2. Content Editor adds descriptions, photos, and translations.
  3. Super Admin checks pricing, creates a departure, and publishes the tour.

3. Customer and booking

  1. Customer finds the published tour and creates a booking.
  2. Customer adds travelers and completes checkout/payment information.
  3. Operations Manager confirms the booking and assigns operational work.

4. Supplier fulfillment

  1. Operations creates and assigns supplier service requests.
  2. The relevant supplier confirms/rejects the request and uploads documents.
  3. Operations reviews the response and advances the workflow in the allowed order.

5. Finance and trip operation

  1. Accounting records and confirms payments.
  2. Customer sees the updated balance.
  3. Operations assigns Tour Leader; Tour Leader then sees the assigned group.
  4. Support Agent handles customer questions and messages.

Security tests required for every role

  • Try the correct menu and expected transaction.
  • Try opening another role's page by typing its URL directly.
  • Verify customers never receive supplier costs or internal margins.
  • Verify suppliers only see their own catalog and assigned requests.
  • Verify country-scoped users only see data for their assigned country.
  • Verify Tour Leaders only see assigned groups and no private payment data.
  • Verify Support cannot confirm payments.
  • Verify invalid workflow/status jumps are rejected.
  • Log out between roles or use a separate private browser window per account.
For ChatGPT or another automated testing app: provide the Replit preview URL separately. Use only these dedicated test accounts. Never provide production credentials, API secrets, database passwords, session cookies, or real customer accounts.
